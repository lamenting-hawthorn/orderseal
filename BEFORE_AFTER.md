# Challenge provenance

## Before this challenge build

OrderSeal did not exist as an application, repository, evaluation result, or
demo. The workspace contained planning and independent-review documents only.

The primary architectural inspiration was BrowserTransactionBench at public
`origin/main` commit `9d01df42768b03e9cc08f5ff9e7beb09b29c6aa1`.
Only these ideas were consulted:

- authoritative database state must outrank agent prose;
- post-commit acknowledgement loss must be distinguished from failed commit;
- ambiguous outcomes should reconcile before any retry;
- effect truth, policy compliance, and claim accuracy should be scored
  separately.

No BrowserTransactionBench source code, fixtures, historical results, test
counts, or receipts are OrderSeal challenge evidence.

## During this challenge build

All OrderSeal application code, synthetic catalogue data, tests, evaluation
cases, trajectories, receipts, measurements, screenshots, and video evidence
are created in this fresh repository after kickoff. External dependencies and
any later source reuse are disclosed in `THIRD_PARTY.md`.
